# The PlayerLobby

The PlayerLobby is a gaming hangout prototype for organizing lobbies, keeping track of friends, and planning group sessions with budgets and settings. It is built with React, JavaScript, and Vite, with lobby and preference data saved in the browser.

## Run locally

1. Install dependencies: `npm install`
2. Start the app: `npm run dev`

This is an in-progress prototype; saved data is stored locally in the browser.
